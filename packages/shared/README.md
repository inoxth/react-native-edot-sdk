# @inox/react-native-edot-shared

Internal shared state for the React Native EDOT SDK.

> **This package is internal.** Do not depend on it directly. Its exports (`ActiveViewContext`, `getNativeModule`, `redactedString`) exist only to break circular dependencies between [`@inox/react-native-edot-sdk`](../react-native) and [`@inox/react-native-edot-navigation`](../react-native-navigation). The API has no stability guarantees and may change without notice.

If you're integrating EDOT into your app, install [`@inox/react-native-edot-sdk`](../react-native) instead.
